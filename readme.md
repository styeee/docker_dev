# Docker-конвейер: сборка → тесты → запуск

Скриптовый конвейер на базе Docker для сборки C++-проекта, прогона чёрных тестов и запуска программы.

## Структура

| Каталог     | Назначение                                                                  |
|-------------|-----------------------------------------------------------------------------|
| `_images/`  | Dockerfile'ы (`builder.docker`, `tester.docker`, `runner.docker`) и скрипты сборки образов |
| `_actions/` | Скрипты запуска контейнеров (сборка, тесты, запуск)                          |
| `src/`      | Исходники на C++ и `CMakeLists.txt`                                          |
| `tests/`    | Тесты чёрного ящика для pytest (файлы вида `*_test.py` / `test_*.py`)        |
| `out/`      | Результат сборки: библиотеки и исполняемые файлы (создаётся автоматически)   |
| `build/`    | Кэши и настройки CMake/Ninja — мусор (создаётся автоматически)               |
| `share/`    | Входные конфиги, выходные данные, логи                                       |

## Быстрый старт

Все скрипты рассчитаны на запуск **из своего каталога** (внутри они сами делают `cd ..`).

### 1. Сборка образов (один раз)

```bash
cd _images && ./build_all.sh
```

### 2. Сборка проекта

Положите исходники и `CMakeLists.txt` в `src/`, затем:

```bash
cd _actions && ./1builder.sh
```

Результат появится в `out/`.

### 3. Тесты

Положите тесты в `tests/`, затем:

```bash
cd _actions && ./2tester.sh
```

Результаты выводятся на экран, логи (если есть) попадают в `share/`.

### 4. Запуск программы

```bash
cd _actions && ./3runner.sh
```

Порт задаётся переменной окружения `port` (по умолчанию 55555):

```bash
port=12345 ./3runner.sh
```

Подключение к программе (порт должен совпадать с портом контейнера):

```bash
ncat localhost 55555
```

## Примечания

- Каталоги `out/` и `build/` создаются Docker автоматически при первом запуске (от имени root).
- Пересборка образов после изменения Dockerfile'ов: `cd _images && ./build.sh <имя>.docker`.
